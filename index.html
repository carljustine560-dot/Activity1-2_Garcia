1. Web Architecture Concepts

CLient Server Model

The client-server model is a network structure where a client program or device asks for a service or data, and a central server processes that request and sends back a response.
This setup powers everyday tasks like browsing web pages, checking email, and using mobile apps.

DNS (Domain Name Sytem)

The Domain Name System (DNS) is the phonebook of the internet that translates human-readable
web names into machine-readable IP addresses.

HTTP vs. HTTPS

HTTP and HTTPS are protocols used to transfer data between your browser and a website,
but HTTPS adds a secure encryption layer to protect your information.
